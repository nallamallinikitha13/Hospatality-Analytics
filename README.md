# 🏨 Hospitality Analytics Project

## 📌 Project Overview
This project analyzes hotel booking data to understand revenue performance, occupancy, booking trends, cancellations, and hotel performance using Excel, SQL, Power BI, and Tableau.

## 🎯 Project Objectives
- Analyze hotel bookings and revenue performance.
- Track occupancy, cancellation, and no-show rates.
- Compare hotel, city, room category, and booking platform performance.
- Build interactive dashboards to support data-driven decisions.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data preparation, Pivot Tables, charts, and KPI calculations.
- **SQL / MySQL:** Database creation, data relationships, joins, and analytical views.
- **Power BI:** Data modeling, Power Query, DAX measures, and interactive dashboards.
- **Tableau:** Calculated fields, filters, and data visualization.

## 📊 Key Performance Indicators (KPIs)
- Revenue Generated and Revenue Realized
- Total Bookings
- Occupancy Rate
- Average Daily Rate (ADR)
- Revenue per Available Room (RevPAR)
- Cancellation Rate
- No-Show Rate
- Average Customer Rating

## 🔍 Key Insights
- Occupancy Rate: **57.87%**
- Revenue Realization Rate: **70.16%**
- Cancellation Rate: **24.83%**
- No-Show Rate: **5.02%**
- Average Customer Rating: **3.62 / 5**
- Highest Revenue City: **Mumbai**
- Largest Booking Platform Category: **Others**
- Most Booked Room Class: **Elite**
